# Design System

## Colours

- Background: `#faf7f1`
- Surface: `#ffffff`
- Muted surface: `#ede7da`
- Foreground: `#252522`
- Muted text: `#5e5b57`
- Border: `rgba(37, 37, 34, 0.09)`
- Primary: `#37463d`
- Primary strong: `#252f29`
- Accent: `#c4735a`

## Typography

- Body: `Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- Headings: `Manrope, Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- Headings use a tight leading, negative tracking, and strong contrast for the editorial feel.

## Spacing

- Section padding: `py-16 sm:py-20 lg:py-24`
- Card padding: `p-5` to `p-6`
- Container width: `max-w-[1240px]`
- Section rhythm uses stacked bands with alternating warm surfaces and white cards.

## Radius

- Primary cards: `rounded-[14px]`
- Secondary surfaces: `rounded-[16px]`
- Utility buttons: `rounded-[8px]`
- Larger panels: `rounded-[18px]`

## Shadows

- Shared shadow token: `0 18px 50px rgba(37, 37, 34, 0.08)`
- Cards and image panels use subtle elevation rather than heavy blur.
